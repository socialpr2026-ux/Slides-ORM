# AI Presentation ORM v0.1

Универсальный технический скелет template-first pipeline для будущей генерации PowerPoint-презентаций по эталону.

## Что делает v0.1

1. Читает конфиг.
2. Находит эталонную PPTX.
3. Находит входящие файлы проекта.
4. Определяет роли файлов по содержанию, а не по названию.
5. Анализирует эталонную PPTX: слайды, shapes, графики, таблицы, изображения.
6. Анализирует Excel / CSV / TXT: листы, диапазоны, первые строки, смысловые признаки.
7. Формирует:
   - `file_inventory.md`
   - `template_map.json`
   - `data_inventory.json`
   - `file_roles.json`
   - `slide_readiness_report.md`
   - `missing_data_report.md`
   - `pipeline_summary.json`

## Чего v0.1 пока не делает

1. Не собирает финальную PPTX.
2. Не обновляет графики.
3. Не заменяет тексты в слайдах.
4. Не генерирует финальные выводы.

Это база для v0.2 и v0.3.

## Запуск

```bash
pip install -r requirements.txt
python run_pipeline.py --config config.example.yaml
```

## Главный принцип

Эталон PPTX задает форму. Любые входящие данные нормализуются и проверяются. Если данных не хватает, скрипт формирует запрос, а не придумывает содержимое.


## Важное уточнение v0.1.1

Для реального проекта лучше использовать `inputs.files`, а не широкий поиск по папке. Это предотвращает подмешивание старых тестовых файлов, архивов и результатов предыдущих запусков.

Пример:

```yaml
inputs:
  files:
    - "/path/to/report.xlsx"
    - "/path/to/analytics.xlsx"
    - "/path/to/export.xlsx"
```
